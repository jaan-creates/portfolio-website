## 2. Key Technical Concepts

- **Vite + React + TypeScript + Tailwind CSS** — SPA, no SSR
- **GSAP + Lenis** — Lenis wired into GSAP ticker at module level in App.tsx (critical: must NOT be moved into useEffect)
- **GSAP ScrollTrigger cleanup** — always use `gsap.matchMedia()` + `mm.revert()` in useEffect cleanup, never kill all triggers globally
- **react-router-dom v6** — BrowserRouter in main.tsx, Routes/Route in App.tsx
- **`--case-accent` CSS variable** — set on CaseStudyLayout outer div, inherited by all child components without prop drilling
- **`--step-*` fluid type scale** — CSS custom properties (clamp-based) added to index.css
- **JetBrains Mono** — added as `font-mono` in Tailwind config and index.html
- **`prefers-reduced-motion`** — all animations check this; GSAP uses matchMedia, CSS animations use media query
- **TypeScript strict mode** — avoid `any`; functional components with typed props
- **One component per file** in `src/components/` (experiments excepted)
- **Tailwind for styling; index.css for global tokens and keyframes only**
